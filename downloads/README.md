# 채점노트 다운로드

이 폴더의 `entry-grading-notebook.zip`을 선택하고 GitHub 파일 화면의 **Download raw file** 버튼으로 내려받으세요.

압축을 풀고 `채점노트.html`을 Chrome 또는 Edge로 여세요. 설치나 API 키는 필요하지 않습니다. 모호한 채점 결과는 교사가 검토하고, 성적표는 JSON 백업으로 보관하세요.

소스와 상세 사용법은 저장소 루트의 README.md를 참고하세요.

웹버전 주소: https://classical96-work.github.io/vibe-coding-work/

버전 1.1부터 정답 난수 범위가 1~10이 아니면 ③ 항목에서 1점 감점합니다. 기존 점수에는 학생 파일 재채점이 필요합니다.

버전 1.2는 추가 블록으로 감점이 사라지던 문제와 정상 분기/모호한 안내의 오판정을 수정했습니다. 저장은 IndexedDB로 이전하며, 이전 버전 기록은 반드시 원본 파일로 재채점하세요. 검토 상태를 엑셀/CSV에도 표시합니다.
